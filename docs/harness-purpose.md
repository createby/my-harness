# 하네스 목적

상태: R2 사용자 승인 완료 (2026-09-29, 기본값 선택).

## 목적 한 문장

허들링 디자이너가 화면 주제를 입력하면, 화면 목록의 모든 화면을 390×844 크기의 Figma 디자인으로 완성하고 확정한 디자인 규칙과 서비스 필수 조건의 위반이 0건인지 검증한다.

## 실행마다 달라지는 입력

디자인할 화면 주제. 예: 자료실, 내 자산, 운영자 검수.

## 사용자

허들링 앱을 디자인하는 디자이너.

## 완료 기준

- 확정된 화면 목록의 모든 화면에 대응하는 Figma 디자인이 존재한다.
- 대상 화면 프레임의 크기는 각각 390×844이다.
- 확정한 디자인 규칙 위반이 0건이다.
- docs/story-service.md의 서비스 필수 조건 위반이 0건이다.

## 후속 확정 사항

- 구체적인 디자인 규칙과 기계 검사 방식은 후속 라운드에서 확정한다.
- 실제 Figma 작업 전에 연결 여부와 대상 파일을 확인한다.
- 이 문서는 목적 확정 기록이며 디자인 제작이나 검증 완료를 뜻하지 않는다.
- 최종 Codex 실행 지침 작성 시 이 목적을 반영한다.
