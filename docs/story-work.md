# 작업 흐름 — 기본값

상태: 사용자 승인 완료 (2026-09-29).
근거: R1-B에서 사용자가 기본값을 선택함.
주의: 사용자의 실제 경험을 확인한 기록이 아니라, 플레이북을 바탕으로 가정한 작업 흐름이다.

## 작업 순서

1. 디자이너가 화면 주제에 맞는 레퍼런스를 수집한다.
2. 디자이너가 레퍼런스에서 반영할 요소를 선택한다. [멈칫: 반영 여부 판단]
3. 디자이너가 화면 목록과 화면 구성을 설계한다.
4. 디자이너가 주요 화면 2~3개를 제작한다.
5. 디자이너가 주요 화면을 담당자에게 넘겨 내부 검토와 승인을 받는다. [넘김: 디자이너 → 검토 담당자] [멈칫: 주요 화면 승인]
6. 디자이너가 승인된 방향을 바탕으로 컴포넌트와 전체 화면을 제작한다.
7. 디자이너가 결과물의 디자인 가이드 위반 여부를 검토한다. [멈칫: 가이드 준수 확인]

## 산출물 후보

- 레퍼런스 목록
- 반영할 요소 목록
- 화면 목록과 화면 구성 설계
- 주요 화면 시안 2~3개
- 내부 검토 결과 및 승인 기록
- 컴포넌트와 전체 화면
- 디자인 가이드 위반 검토 결과

## 게이트 위치 후보

- 반영할 요소 선택 후
- 주요 화면 제작 후 내부 승인 시점
- 전체 화면 제작 후 가이드 준수 검토 시점

## 역할 경계 후보

명시된 인계는 주요 화면 제작 후 디자이너에서 검토 담당자로 넘기는 지점이다.
자동화 에이전트의 역할과 편집 권한은 R6에서 별도로 확정한다.
